# 军棋 · Junqi Battle（安卓）

> 传统陆战棋（军棋）安卓单机游戏，重构版。包含两种经典玩法：**翻棋** 与 **背靠背暗棋布局**。
> 技术方案：HTML5 Canvas + 原生 JS 规则引擎，Capacitor 打包 Android APK。完全离线、无广告、无账号。

当前阶段：**迭代 0（文档奠基）** — 仅产出产品与技术文档，暂无游戏代码。代码从迭代 1 开始。

---

## 两种玩法

### ① 翻棋（Flip）
50 枚棋子随机扣放在棋盘上，双方开局都不知道棋子归属与军衔。每回合只能做一件事：**翻开一枚棋子**，或
**移动一枚自己已翻开的棋子**。玩法核心是运气、记忆与推理——你既在找自己的部队，也在推断对手的部队。

### ② 背靠背暗棋布局（Back-to-Back）
正统军棋对局方式。开局前双方**背对背各自暗布阵型**（军旗进大本营、地雷只放最后两排、炸弹不上第一排、
行营不布子），阵型对对手完全隐藏，交战后由系统充当裁判逐步揭示。考验布阵思路、试探与判断。

两种玩法均支持 **单机 AI** 与 **本地双人热座**。

## 技术栈

- **渲染**：HTML5 Canvas（不引入渲染框架）
- **逻辑**：Vanilla JavaScript，规则引擎与 UI 完全解耦，可在 Node 下单测
- **打包**：Capacitor（Web → Android APK）
- **测试**：Node 内置 `node:test` + 无头 DOM 冒烟测试
- **构建环境**：JDK 17（已具备）+ Android SDK command-line tools（打 APK 前需安装）
