# 迭代规划（ROADMAP）

> 一个迭代 = 一个可验证的交付。每个迭代必须有明确的退出标准，未达标不进入下一迭代。
> 迭代完成后在 `docs/迭代记录.md` 追加记录。当前进度：**迭代 0 已完成**。

---

## 迭代 0 · 项目奠基（文档先行）✅
**目标**：把"做什么、按什么规则做、怎么验收"定义清楚，避免像 v1 那样规则埋在代码里。

**交付**
- GitHub 仓库 + `.gitignore` + README（含文档索引与迭代纪律）
- `docs/PRD.md`：背景、目标、用户故事、功能清单、EARS 需求、流程、交互、指标、验收标准、待确认问题
- `docs/规则说明.md`：棋盘模型、棋子表、吃子判定表、走子规则、两种玩法细则、规则开关
- `docs/ARCHITECTURE.md`：分层、数据模型、引擎 API、AI 设计、测试与打包
- `docs/ROADMAP.md`、`docs/迭代记录.md`

**退出标准**：主公评审通过 PRD 与规则说明；Q-1…Q-7 中影响走法的 Q-1 必须有结论。

## 迭代 1 · 规则引擎 + 连通图自检 ✅
**目标**：跑通规则内核，先确保"棋盘对、走法对、结算对"。

**交付**
- `board.js` 棋盘几何与铁路/公路邻接表
- `pieces.js` 棋子与吃子结算
- `engine.js` 对局状态机：`createGame / legalMoves / allLegalActions / applyAction / undo / viewFor / serialize`
- **连通图可视化自检页**（`www/debug.html`）：点任一格高亮其公路邻接、铁路可达，用于与实体棋盘图比对
- `test/engine.test.js`：吃子表 12 组合、铁路直行/工兵转弯、阻挡、行营保护、大本营锁定、胜负判定

**退出标准**：单测全绿；自检页与棋盘图逐项核对通过；规则说明 D-1/D-2 结论回写文档。

## 迭代 2 · 两种玩法可玩（热座） ✅ 已完成
**目标**：不含 AI 也能完整玩起来。

**交付**
- 翻棋：随机扣放、翻子/走子回合、背面子障碍语义（game.html?mode=flip）
- 暗棋：布阵页（随机 + 手动 + L-1..L-6 校验与定位提示）、热座交接遮挡页、裁判制揭示（layout.html → game.html?mode=hidden）
- 对局页 Canvas UI：选中高亮、合法落点、上一手标记、战斗提示条、结算弹层、悔棋/重开
- 首页与设置页骨架（index.html，含规则弹层；AI 入口预留但迭代 3 启用）
- 引擎补充：战斗后向双方揭示参战子（revealMode=result），更符合热座直觉

**退出标准**：两种玩法逻辑跑通（22 项单测 + 集成测试全绿）；页面脚本在 DOM 桩下零初始化报错；违规布阵被 applyLayout 拦截。真机/浏览器竖屏视觉验证待用户侧确认。

## 迭代 3 · 单机 AI ✅ 已完成
**目标**：一个人能玩，且 AI 不送子。

**交付**
- `ai.js` 三档难度（easy 随机偏吃 / normal 一层评估 / hard 2 层搜索 + 概率估计）
- AI 思考态与耗时控制（200–900 ms，分片不卡 UI）
- 视野隔离：AI 仅用 `viewFor(side)` 等价信息，不读取未揭示敌子身份
- 自对弈压力测试：1000 局无异常、必然终局
- 前端接入：首页可选「人机对战 + 难度」；暗棋 AI 模式仅人类(黑)布阵、AI(红)随机布阵；对局页 AI 回合循环 + 思考指示（无热座交接遮罩）

**退出标准**：普通档对随机档胜率 > 90%（实测 10/10）；人机对局无长时间卡顿；自对弈无死循环。

---

## 迭代 4 · 体验与状态管理 ✅ 已完成
**目标**：从"能玩"到"愿意反复玩"。

**交付**
- 存档续局：对局每步自动写入 `localStorage`（`junqi_save_v1`，含 mode/opp/level/humanSide/finished/序列化状态）；首页检测未完成存档显示「继续上局」，进入对局页 `?resume=1` 从存档恢复（含 AI 模式，恢复后轮到 AI 则自动行动）。
- 悔棋：多步悔棋；人机模式下一直退到「轮到人类」为止，避免退到 AI 回合又被自动重走；悔棋后不自动调度 AI，交回人类决策。
- 阵型库：布阵页可保存当前阵型为命名阵型、一键套用预设（均衡 / 进攻 / 防守）、载入/删除我的阵型；预设与用户阵型均以黑方坐标存储，红方使用时镜像。
- 设置页规则开关落地（`mineHitRule` / `revealMode` / `flipMoveMode`）——开关已内置引擎 `defaultRules`，本轮 UI 未单独做开关面板（留待迭代 5 打磨时可视化）。

**退出标准**：杀进程后可续局；悔棋后状态与历史完全一致（含 AI 应手）；预设阵型经验证均为合法布局。
