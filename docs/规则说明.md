## 1. 棋盘模型

### 1.1 坐标系

- 棋盘为 **12 行 × 5 列 = 60 格**，竖屏布局。
- 行索引 `r = 0..11`（上 → 下），列索引 `c = 0..4`（左 → 右），格位记为 `(r,c)`。
- **上方为黑方（black）**：`r = 0..5`；**下方为红方（red）**：`r = 6..11`。
- `r = 5` 与 `r = 6` 之间为 **山界（前线）**，双方各自的 `r=5` / `r=6` 称为**第一排（前排）**。
- 每方 30 格 = 2 大本营 + 5 行营 + 23 兵站。

### 1.2 特殊格位

| 类型 | 黑方坐标 | 红方坐标 | 数量/方 |
| --- | --- | --- | --- |
| 大本营（HQ） | (0,1)、(0,3) | (11,1)、(11,3) | 2 |
| 行营（Camp） | (2,1)、(2,3)、(3,2)、(4,1)、(4,3) | (7,1)、(7,3)、(8,2)、(9,1)、(9,3) | 5 |
| 兵站（Post） | 其余格位 | 其余格位 | 23 |

示意（`■`=大本营，`○`=行营，`·`=兵站）：

```
        c0  c1  c2  c3  c4
 r0      ·   ■   ·   ■   ·      黑方后排
 r1      ·   ·   ·   ·   ·      ← 横向铁路
 r2      ·   ○   ·   ○   ·
 r3      ·   ·   ○   ·   ·
 r4      ·   ○   ·   ○   ·
 r5      ·   ·   ·   ·   ·      ← 横向铁路（黑方前排）
========================== 山界 ==========================
 r6      ·   ·   ·   ·   ·      ← 横向铁路（红方前排）
 r7      ·   ○   ·   ○   ·
 r8      ·   ·   ○   ·   ·
 r9      ·   ○   ·   ○   ·
 r10     ·   ·   ·   ·   ·      ← 横向铁路
 r11     ·   ■   ·   ■   ·      红方后排
```

### 1.3 铁路网（Railway）

- **横向铁路**：`r1`、`r5`、`r6`、`r10` 四行，各行 `c0..c4` 全线连通。
- **纵向铁路（侧翼）**：`c0` 与 `c4`，从 `r1` 到 `r10` 连续贯通（自然跨越山界）。
- **山界中路（中线桥）**：`(5,2) ↔ (6,2)` 为铁路，连接双方前排横线。
- **三条铁路过界**：山界仅由 `(5,0)-(6,0)`、`(5,2)-(6,2)`、`(5,4)-(6,4)` 三处铁路桥连通两方势力（即"两方势力通过三条铁路连接"），其余列（c1、c3）山界处**无铁路**。
- 行营与后排（`r0`/`r11`）**不在铁路上**；`c2` 列除中线桥外**不是**纵向铁路（故行营 `(3,2)`/`(8,2)` 不在铁路上）。
- 判定函数：`isRail(r,c)` — 满足 `r∈{1,5,6,10}` 或 `c∈{0,4} 且 1≤r≤10`。中线桥仅作为铁路**边** `(5,2)-(6,2)` 加入 `railAdj`，不改变 `isRail` 单元判定。
- **已锁定（D-2 已决）**：`(5,2)↔(6,2)` 确定为铁路。

### 1.4 公路网（Road）

- 所有**正交相邻**格位之间有公路（上下左右），**含跨山界**：`(5,c) ↔ (6,c)` 在 `c = 0..4` **五列全通**（每列一步即可过界）。【D-1 已决：公路五列全通】
- **铁路桥同时也是公路桥**：c0/c2/c4 三处既通铁路也通公路；c1/c3 仅通公路、不通铁路。
- **行营斜线**：行营与其四个斜对角格位之间有公路（这是标准棋盘的特有连线，不可漏）。
  例：`(3,2)` 与 `(2,1)`、`(2,3)`、`(4,1)`、`(4,3)` 相连。
- 公路连线仅供**一步移动**使用，不能长驱。

### 1.5 连通图生成

`board.js` 在初始化时预生成两张邻接表：`roadAdj[cell] = [cells...]`、`railAdj[cell] = [cells...]`，
运行期只读，不随对局变化。棋盘几何一旦确定即冻结，所有走法计算基于这两张表。

| --- | --- | --- | --- | --- |
| 司令 | 1 | 9 | 是 | 阵亡后本方军旗立即揭示 |
| 军长 | 1 | 8 | 是 | |
| 师长 | 2 | 7 | 是 | |
| 旅长 | 2 | 6 | 是 | |
| 团长 | 2 | 5 | 是 | |

| 连长 | 3 | 3 | 是 | |

## 3. 吃子判定表（唯一权威）

进攻方 A 主动移动到防守方 B 所在格位时按下表结算：

| A \ B | 普通子（衔高） | 普通子（衔低） | 普通子（同衔） | 地雷 | 炸弹 | 军旗 |
| --- | --- | --- | --- | --- | --- | --- |
| 普通子（非工兵） | A 亡 | B 亡 | 双亡 | **双亡**（默认） | 双亡 | A 胜（夺旗） |
| 工兵 | A 亡 | B 亡 | 双亡 | **B 亡**（排雷成功） | 双亡 | A 胜（夺旗） |
| 炸弹 | 双亡 | 双亡 | 双亡 | 双亡 | 双亡 | A 胜（夺旗） |

补充判定：

1. **地雷、军旗不可主动移动**，因此永不作为进攻方 A 出现。
2. **行营保护**：行营内的棋子不可被攻击（任何棋子不得移动到已被敌方棋子占据的行营）。
3. **大本营**：棋子一旦进入大本营即**不可再移出**（永久驻留）；大本营内的棋子可以被攻击。
4. **司令阵亡**：任一方司令阵亡时，该方军旗立即对双方揭示（不影响其位置与胜负判定）。
5. 结算后如任一方军旗被吃 → 立即判负，对局结束。

## 4. 走子规则

一次移动只能选择**一枚己方可移动棋子**，沿以下任一路径走到目标格：

### 4.1 公路移动（所有可移动棋子）
- 沿公路连线走 **1 步**，目标格为空 → 移动；目标格为敌子 → 进入战斗结算；目标格为己方棋子 → 非法。

### 4.2 铁路移动（起点在铁路上）
- **工兵**：可在铁路网上沿铁路线任意行走，**允许转弯**，步数不限，路径上不得有任何棋子（含己方与敌方，含暗棋背面子）。
- **其他可移动棋子**：只能沿**同一条直线铁路**（同行或同列）直行任意步数，**不得转弯**，路径中间不得有任何棋子。
- 终点判定与公路一致（空格移动 / 敌子战斗 / 己子非法 / 敌方行营非法）。

### 4.3 非法走法（统一拒绝）
- 目标格为己方棋子。
- 目标格为敌方棋子且该格是行营。
- 起点棋子为地雷、军旗，或已进入大本营。
- 铁路长驱路径中间有任何棋子阻挡。
- 不属于当前行动方的棋子。

## 5. 玩法 A：翻棋（Flip）

### 5.1 开局
- 50 枚棋子（双方各 25）**完全随机**扣放在 50 个非行营格位上（`60 - 10 个行营 = 50`），行营开局为空。
- 双方均不知道任何棋子的归属与军衔。

### 5.2 回合行动（二选一）
1. **翻棋**：翻开任意一枚仍为背面的棋子，揭示其归属与军衔，回合结束（不可翻完再走）。
2. **走子**：移动一枚**已翻开且属于自己**的棋子（走法遵循第 4 节），可吃子。

- 先手第一手**必须翻棋**。
- 背面棋子视为**障碍**：不可被攻击、不可被穿越、不可被移动。
- 翻开后的地雷、军旗仍不可移动。
- 归属由翻开结果决定：翻到对手的棋子，也照常揭示，成为对手的可用棋子。

### 5.3 胜负
- 夺取对方军旗 → 胜。
- 对方**无任何合法行动**（无背面子可翻，且无己方明子可动）→ 对方负。
- 双方均无合法行动 → 和棋。
- 步数上限（默认 300 手）内无战斗发生则判和（防止僵局）。

### 5.4 翻棋走法开关
- `flipMoveMode = "full"`（默认）：沿用第 4 节完整走法（含铁路长驱与工兵转弯）。
- `flipMoveMode = "simple"`：仅允许公路一步，忽略铁路特权（更适合休闲/新手）。

## 6. 玩法 B：背靠背暗棋布局（Back-to-Back）

### 6.1 布阵阶段
双方各自将 25 枚棋子布置到本方 25 个可布格位（23 兵站 + 2 大本营），约束如下：

| 编号 | 布阵约束 |
| --- | --- |
| L-1 | 军旗**必须**放在本方两个大本营之一 |
| L-2 | 地雷**只能**放在本方最后两排（黑方 `r0`/`r1`，红方 `r10`/`r11`） |
| L-3 | 炸弹**不得**放在本方第一排（黑方 `r5`，红方 `r6`） |
| L-4 | 行营**不得**布子（开局必须为空） |
| L-5 | 另一个大本营可放任意非军旗棋子，也可留空；但 25 枚棋子必须全部落位 |
| L-6 | 布阵不合法时不允许开始对局，UI 需明确提示违规项 |

- 支持 **随机布阵**、**手动布阵**、**保存/载入自定义阵型**（阵型模板见 ROADMAP 迭代 4）。
- **热座双人**：一方布阵完成后进入遮挡过渡页（"请将手机交给对手，对手勿看上一屏"），确认后对手开始布阵。
- **人机对局**：AI 使用内置阵型库随机选取并做扰动，不得读取玩家阵型。

### 6.2 对局阶段
- 双方棋子对对手**始终显示为背面**，己方棋子对自己完全可见。
- 系统充当**裁判**，仅在发生战斗时公布结果，揭示程度由开关控制：
  - `revealMode = "result"`（默认）：只公布"谁亡/双亡"，被吃子揭示军衔，存活的胜方棋子**不揭示**军衔。
  - `revealMode = "full"`：交战双方棋子军衔全部揭示。
- 司令阵亡 → 该方军旗立即揭示（见 3.4）。

### 6.3 胜负
- 夺取对方军旗 → 胜。
- 对方无任何合法走法 → 对方负。
- 一方主动认输 → 对方胜。
- 步数上限（默认 400 手）内无战斗 → 判和。

## 7. 规则开关汇总（可配置项）

| 开关 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `mineHitRule` | `"both"` / `"attackerOnly"` | `"both"` | 非工兵碰雷：双亡 / 仅进攻方亡（地雷留存） |
| `flagCaptureNeedsMines` | `true` / `false` | `false` | 是否必须先排除对方 3 颗地雷才能夺旗（"三雷不出不许扛旗"） |
| `revealMode` | `"result"` / `"full"` | `"result"` | 暗棋战斗揭示程度 |
| `flipMoveMode` | `"full"` / `"simple"` | `"full"` | 翻棋走法是否含铁路特权 |
| `hqLockIn` | `true` / `false` | `true` | 进入大本营的棋子是否禁止再移出 |
| `maxMovesNoBattle` | 整数 | 300 / 400 | 无战斗判和步数（翻棋 / 暗棋） |

所有开关集中在 `engine.js` 的 `defaultRules` 对象，UI 在"设置"页暴露一部分；引擎不得硬编码规则常量。
